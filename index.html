ClipHistory

A lightweight clipboard history manager for macOS

Download v1.0.1 (.dmg) GitHub

USAGE

Press ⌘ + B to choose and re-copy from your clipboard history

/ INSTALLATION & NOTES

Installation

  1. Download the latest ClipHistory.dmg from the Releases page
  2. Open the dmg and drag ClipHistory.app to /Applications

If a Warning Appears on First Launch

If macOS security (quarantine attribute) prevents the app from opening, run the following in Terminal:

sudo xattr -cr /Applications/ClipHistory.app
